Smallest with 12 divisors

The question What is the smallest positive integer that has exactly 12 positive divisors?
06Work backward from the divisor count

If n = pa × qb × rc, then n has (a + 1)(b + 1)(c + 1) divisors. Split the target count into factors, subtract 1 from each to get powers, and give the biggest power to the smallest prime.

3 × 22, 12² × 3 = 12
Try every way to split the count. Splitting into more primes is often smaller, but check every option.

Step by step

  1. Recall the rule

    From problem 4: if n = 2a × 3b × 5c, the number of divisors is (a + 1)(b + 1)(c + 1). We need this product to be 12.

  2. List the ways to make 12

    Order does not matter, and leave out factors of 1.

    12 6 × 2 4 × 3 3 × 2 × 2

  3. Turn each way into powers

    Subtract 1 from each factor.

    12 → power 11 6 × 2 → powers 5, 1 4 × 3 → powers 3, 2 3 × 2 × 2 → powers 2, 1, 1

  4. Build the smallest number for each

    Put the biggest power on 2, the next on 3, then 5. For example 25 × 3 = 96, but 35 × 2 = 486.

    211 = 2048 25 × 3 = 96 2³ × 3² = 72 2² × 3 × 5 = 60

  5. Pick the smallest

    60

  6. Check

    List the divisors of 60.

    1, 2, 3, 4, 5, 6, 10, 12, 15, 20, 30, 60 → 12
60

How to spot this type: “smallest number with exactly N divisors”. List every way to write N as a product, turn each into powers, and build the smallest number for each one. Do not stop after the first one you try.
