When is p² + 2 prime?

The question Find every prime number p for which p² + 2 is also prime.
07Every prime above 3 sits next to a multiple of 3

Divide any whole number by 3 and the remainder is 0, 1 or 2. A prime bigger than 3 cannot have remainder 0, so it is one more or one less than a multiple of 3. Its square always has remainder 1.

Check the small primes 2 and 3 by hand. Then use remainders to handle every other prime at once.

Step by step

  1. Try small primes

    Every answer after p = 3 divides by 3.

    p = 2: 4 + 2 = 6 not prime p = 3: 9 + 2 = 11 prime p = 5: 25 + 2 = 27 = 3 × 9 p = 7: 49 + 2 = 51 = 3 × 17 p = 11: 121 + 2 = 123 = 3 × 41

  2. Write a prime above 3 using 3k

    A prime above 3 does not divide by 3. So it is 3k + 1 or 3k − 1 for some whole number k. For example 7 = 3 × 2 + 1 and 11 = 3 × 4 − 1.

  3. Square it

    In both cases the square is a multiple of 3, plus 1.

    (3k + 1)² = 9k² + 6k + 1 = 3(3k² + 2k) + 1 (3k − 1)² = 9k² − 6k + 1 = 3(3k² − 2k) + 1

  4. Add 2

    p² + 2 is a multiple of 3, plus 3, so it is a multiple of 3. It is also bigger than 3, so it cannot be prime.

    p² + 2 = (multiple of 3) + 1 + 2 = (multiple of 3) + 3

  5. Only 2 and 3 are left

    Step 1 already checked them: p = 2 fails and p = 3 works.

Only p = 3 works (3² + 2 = 11).

How to spot this type: “find all primes p such that” some formula is also prime. Test small primes, notice which number keeps dividing the result, then prove it with remainders. Remainders by 3 work most often, and remainders by 2, 4 or 5 sometimes do.
