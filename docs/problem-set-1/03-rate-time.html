Problem 3 · Rate, time and distance

Kris and Susie run 100 meters

The question Kris and Susie are running a 100-meter race. Both run at constant speeds. Susie's running speed is 1.25 meters per second faster than Kris's running speed, and she finishes the race 4 seconds faster than Kris. How many seconds does Susie take to finish the race?
Hint 1
03Same distance, two rates

Both runners cover the same distance. Call the slower time t, so the faster time is t minus the head start you were given. Speed is distance divided by time, and that turns the speed gap into an equation.

Susiet − 4
Multiply out the fractions and you get a quadratic equation. Drop the negative answer. Then check whose time the question asked for.
Hint 2

Call Kris's time t seconds, so Susie's time is t − 4. Each speed is 100 divided by that runner's time. Susie's speed minus Kris's speed is 1.25.

Step-by-step solution

Step by step

  1. Name one unknown

    Let t be the number of seconds Kris takes. Susie finishes 4 seconds sooner, so her time is t − 4.

  2. Write each speed

    Both run 100 meters, so divide 100 by each runner's time.

    Kris's speed = 100 / t Susie's speed = 100 / (t − 4)

  3. Turn the speed gap into an equation

    Susie's speed is 1.25 m/s more than Kris's.

    100/(t − 4) − 100/t = 1.25

  4. Clear the fractions

    Multiply every term by t(t − 4).

    100t − 100(t − 4) = 1.25 · t(t − 4) 100t − 100t + 400 = 1.25t² − 5t 400 = 1.25t² − 5t

  5. Tidy up and factor

    Divide both sides by 1.25 to get whole numbers.

    320 = t² − 4t t² − 4t − 320 = 0 (t − 20)(t + 16) = 0

    A time cannot be negative, so t = 20.

  6. Answer the right runner

    t = 20 is Kris's time. Susie takes 4 seconds less.

    20 − 4 = 16 seconds

  7. Check both facts

    TimeSpeed
    Kris20 s100 ÷ 20 = 5 m/s
    Susie16 s100 ÷ 16 = 6.25 m/s

    The speeds differ by 1.25 and the times differ by 4. Both match the question.

Susie takes 16 seconds.

How to spot this type: two people, one shared distance, and you are told the gap between their speeds and the gap between their times. Name the slower time t, write the faster one as t minus the gap, and the rest is algebra. Factoring beats the quadratic formula when the numbers are friendly, so always try it first.
