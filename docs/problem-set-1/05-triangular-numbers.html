Problem 5 · Triangular numbers

The greatest n with 1 + 2 + 3 + … + n under the limit

The question What is the greatest positive integer n for which 1 + 2 + 3 + 4 + … + n ≤ 2026?

The limit was cut off in the photo of the worksheet. It reads 20__, so it is 2025 or 2026. Both give the same answer.
Hint 1
05Two staircases make a rectangle

Stack 1 + 2 + 3 and so on as a staircase. Turn a second copy upside down and drop it on top. The two fill a solid rectangle n wide and n+1 tall, so one staircase is half of it.

rectangle = n(n+1)
staircase = n(n+1)/2
shown with n = 4
To find the biggest n under a limit, start near the square root of twice that limit. Test that n and the one after it. The question asks for n, not for the sum.
Hint 2

1 + 2 + … + n = n(n + 1) ÷ 2, so you need n(n + 1) ≤ 2 × 2026 = 4052. Which whole number squared comes close to 4052?

Step-by-step solution

Step by step

  1. Replace the long sum with the formula

    Adding 1 through n gives half of an n by n+1 rectangle.

    1 + 2 + 3 + … + n = n(n+1) / 2

  2. Write the condition

    n(n+1) / 2 ≤ 2026 n(n+1) ≤ 4052

  3. Estimate n before testing

    n(n+1) sits close to n², so take the square root of 4052. It is a bit over 63, because 63² = 3969 and 64² = 4096.

  4. Test 63 and 64

    nn(n+1)SumUnder 2026?
    6363 × 64 = 40322016yes
    6464 × 65 = 41602080no

    63 fits and 64 does not, so 63 is the greatest one.

  5. Answer n, not the sum

    The sum at n = 63 is 2016. The question asks for n.

n = 63
