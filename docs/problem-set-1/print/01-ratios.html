Problem 1 · Ratios

Andy, Jason and 35 tennis matches

The question Andy won 3 out of every 5 tennis matches that he played against Jason. If they played 35 matches in total, how many of them did Jason win?
01A ratio is equal groups

“3 out of every 5” breaks the whole into groups of 5. Each group hands 3 to one side and 2 to the other. Count the groups first.

The parts add back to the whole: 3 + 2 = 5. Read the question again to see which part it wants.

Step by step

  1. Read the ratio as one group

    Every 5 matches split the same way. Andy takes 3 and Jason takes the rest.

    one group = 5 matches = 3 Andy + 2 Jason

  2. Count how many groups fit in 35

    Divide the total by the size of one group.

    35 ÷ 5 = 7 groups

  3. Multiply each part by the number of groups

    Andy: 3 × 7 = 21 Jason: 2 × 7 = 14

  4. Pick the one the question asked for

    The question names Jason, so the answer is his 14.

  5. Check

    The two parts should rebuild the total.

    21 + 14 = 35  ✓
Jason won 14 matches.
