Solving quadratic equations

This page starts from what a quadratic is and builds up, one small step at a time, to the quadratic formula. By the end you will know where the formula comes from, not just what it says.

QCThe quick card

A quadratic equation looks like ax² + bx + c = 0.

1. Try factoring first. Find two numbers that multiply to c and add to b. Each bracket gives an answer.

x² + 6x + 5 = 0 multiply to 5, add to 6: 1 and 5 (x + 1)(x + 5) = 0 → x = −1 or x = −5

2. If it will not factor, use the formula.

x = −b ± √(b² − 4ac)2a
The number under the square root, b² − 4ac, tells you how many answers there are: two if it is positive, one if it is 0, none if it is negative.

1 · What a quadratic equation is

A quadratic equation has an x² term and no higher power. Move every term to one side so the other side is 0. Then it looks like this:

ax² + bx + c = 0 2x² + 3x − 2 = 0 → a = 2, b = 3, c = −2 x² − 9 = 0 → a = 1, b = 0, c = −9

The numbers a, b and c are called the coefficients. Keep the sign with each one: in 2x² + 3x − 2, c is −2, not 2. A quadratic usually has two answers, because two different numbers can have the same square: 3² = 9 and (−3)² = 9.

2 · Method 1: factor

If two numbers multiply to 0, at least one of them is 0. So if you can write the quadratic as (one bracket) × (another bracket) = 0, each bracket gives an answer.

For x² + bx + c, look for two numbers that multiply to c and add to b.

x² + 6x + 5 = 0 multiply to 5, add to 6: 1 and 5 (x + 1)(x + 5) = 0 x + 1 = 0 or x + 5 = 0 x = −1 or x = −5

Factoring is the fastest method when it works. But many quadratics, like x² + 4x + 1 = 0, have no whole numbers that fit. For those you need a method that always works.

3 · Method 2: complete the square

The idea: if one side is a perfect square, like (x + 3)², you can undo the square with a square root. Here is how to turn x² + 6x into a perfect square, using a picture.

Draw x² as a square with side x. Split 6x into two strips, each 3 by x, and put one on the right and one along the bottom.

x² + 6x drawn as a square x by x and two strips 3 by x. The dashed corner is missing, so the shape is not yet a full square. Not to scale.

The corner is missing. It is 3 by 3, so it has area 9. Add 9 and the shape becomes a full square with side x + 3.

Adding the 3 by 3 corner, area 9, makes a full square with side x + 3. So x² + 6x + 9 = (x + 3)². Not to scale.

Now solve x² + 6x + 5 = 0 this way. Whatever you add to one side, add to the other side too.

x² + 6x + 5 = 0 x² + 6x = −5 move the 5 across x² + 6x + 9 = −5 + 9 add the missing corner, 9 (x + 3)² = 4 the left side is now a square x + 3 = 2 or −2 square root, both signs x = −1 or −5 subtract 3

The same answers as factoring. The corner is always (half of b)²: here half of 6 is 3, and 3² = 9.

4 · Where the formula comes from

Now do exactly the same steps with letters instead of numbers. Every step is one you just did in section 3.

ax² + bx + c = 0 step 1 divide by a, so x² has no number in front: x² + (b/a)x + c/a = 0 step 2 move c/a across: x² + (b/a)x = −c/a step 3 half of b/a is b/(2a). Add its square to both sides: x² + (b/a)x + b²/(4a²) = b²/(4a²) − c/a step 4 the left side is a square. Put the right side over 4a²: (x + b/(2a))² = (b² − 4ac)/(4a²) step 5 square root, both signs. √(4a²) = 2a: x + b/(2a) = ±√(b² − 4ac) / (2a) step 6 subtract b/(2a): x = (−b ± √(b² − 4ac)) / (2a)

That last line is the quadratic formula:

x = −b ± √(b² − 4ac)2a

In step 4, c/a became 4ac/(4a²) so both parts share the same bottom. That is the only new trick.

5 · Using the formula

Write down a, b and c with their signs, put them into the formula, and work out the part under the root first.

2x² + 3x − 2 = 0 a = 2, b = 3, c = −2 under the root: b² − 4ac = 3² − 4 × 2 × (−2) = 9 + 16 = 25 √25 = 5 x = (−3 + 5) / 4 = 2/4 = 1/2 x = (−3 − 5) / 4 = −8/4 = −2

And one that does not factor:

x² + 4x + 1 = 0 a = 1, b = 4, c = 1 under the root: 4² − 4 × 1 × 1 = 16 − 4 = 12 √12 = √4 × √3 = 2√3 x = (−4 ± 2√3) / 2 = −2 ± √3 x ≈ −0.27 or x ≈ −3.73

Watch the signs: when c is negative, −4ac becomes positive, as in 9 + 16 above. And −b means “the opposite of b”: if b = −5, then −b = 5.

6 · How many answers? Look under the root

The part under the square root, b² − 4ac, is called the discriminant. You can check it before doing any other work.

b² − 4acanswersexample
positivetwox² + 6x + 5: 36 − 20 = 16
zeroonex² − 6x + 9: 36 − 36 = 0, so x = 3
negativenonex² + 2x + 5: 4 − 20 = −16

A negative number has no real square root, because any real number squared is 0 or more. So a negative discriminant means no real answers.

Always check which answers make sense. A length, a time or an age cannot be negative, so in a word problem you often throw one answer away.

Check yourself

1. Solve x² − 2x − 15 = 0 by factoring.

Answer:

multiply to −15, add to −2: −5 and 3 (x − 5)(x + 3) = 0 → x = 5 or x = −3

2. Solve x² + 8x − 9 = 0 by completing the square.

Answer:

x² + 8x = 9 half of 8 is 4, and 4² = 16: x² + 8x + 16 = 9 + 16 (x + 4)² = 25 x + 4 = 5 or −5 → x = 1 or x = −9

3. Solve 3x² − 5x − 2 = 0 with the formula.

Answer:

a = 3, b = −5, c = −2 b² − 4ac = 25 − 4 × 3 × (−2) = 25 + 24 = 49, √49 = 7 x = (5 + 7) / 6 = 2 x = (5 − 7) / 6 = −2/6 = −1/3

4. Without solving, how many answers does x² + 2x + 5 = 0 have?

Answer:

b² − 4ac = 4 − 20 = −16, which is negative, so no real answers
